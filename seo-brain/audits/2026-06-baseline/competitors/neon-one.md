## 8. Attack / Defend / Lateral Notes

**ATTACK (where DonorDock should press):**
- **Pricing transparency / TCO wedge.** Neon's "$99 starting" headline + 3 tiers + ~3% processing + $25 donation add-on + revenue step-ups = quote shock. Third parties (PricingNow) now publish "True TCO & Hidden Costs of Neon" content — validates the wedge. Ship our own "Real cost of Neon CRM" calculator/article.
- **"Best CRMs for Small Nonprofits 2026" SERP.** Still the single most damaging page to our ICP capture — and it now names us, so the long-tail "DonorDock vs Neon for small nonprofits" intent increasingly resolves on *their* page. DonorDock's /articles/best-nonprofit-crm + /articles/small-nonprofits-crm must outrank it. Lean on ease-of-use + G2 sub-score lead.
- **Annual research counter (still Priority 1).** Neon's Recurring Donor Report (4,107 nonprofits / 718 donors / PR Newswire + Rutland Herald) is now fully operationalized into stat pillars and a spin-off statistics page. We still have no annual-research franchise. Ship "The Lean Fundraiser Report" or similar named research with a DonorDock-data hook.
- **AEO/GEO crawlability gap.** Cloudflare 403 on neonone.com unchanged. Our llms.txt + clean robots.txt + Content-Signal header remains a unilateral advantage for AI-grounded queries — push more quotable "stat card" content into pillars to be the citable source when AI engines can't reach Neon.

**DEFEND (where Neon could hurt us):**

- **Content velocity + primary research.** Multi-post/week + 800–1,200 posts, now layering primary interviews (50+) into evergreen pillars. We can't match volume — match relevance with sharper ICP pillars.
- **They now control the narrative on us.** With DonorDock named inside Neon's high-ranking listicles, monitor how they frame us each refresh. If favorable framing turns negative, escalate to a counter-pillar.
- **Author E-E-A-T.** Tim Sarrantonio's external presence still unmatched. Name/promote Rob & Matt as DonorDock's public "lean fundraiser" voices.

**LATERAL:**
- **Third-party "Neon alternatives" listicles** (SoftwareAdvice, SelectHub, GetApp, Zeffy, Rooted Software, Double the Donation) consistently include DonorDock. Zeffy and Rooted now run head-to-head Neon-vs-DonorDock pages. Quarterly outreach with fresh sub-scores/customer count/quote = free placements.
- **Association segment.** Association tiers stable; not our segment — flag only for product/strategy.
