# Opportunities

Monthly content opportunity reports generated by the `donordock-seo-strategist` skill (Phase 3).

## Naming

`opportunities/YYYY-MM.md`

## Cadence

1st of each month. Appended, never overwritten.

## Report contents

- Pillar coverage gaps (pillars underserved by current content)
- AEO CMS page opportunities (intent-specific landing hubs like the existing Solutions pages)
- Long-tail keyword wins (low competition × decent volume × aligned to pillar)
- Competitor content to respond to or beat
- Trending / seasonal opportunities (GivingTuesday, year-end, etc.)
- Podcast episode leverage (FF episodes to expand into pillar articles)

## Per-opportunity fields

- Type (article / CMS page / pillar page / comparison / update existing)
- Target keywords
- Pillar
- Content type
- Effort estimate
- Draft brief (200-word outline)
- Expected impact (estimate: traffic, citations, conversions)
- Priority

## Workflow

1. Strategist skill generates report on 1st of month
2. Rob reviews, marks approved items
3. Strategist creates Asana tasks for approved items (Phase 8)
4. Items feed into content pipeline
