# Content Pillars

> **Status:** Placeholder — populated in Phase 2 from Phase 1 baseline audit findings.

Pillars are topical authority areas where DonorDock wants to be THE definitive answer. Each pillar:

- Maps to a core ICP need
- Has 15-30 supporting articles
- Connects to a target keyword cluster in `keyword-universe.md`
- Anchors to a pillar page (comprehensive guide)
- Supports AEO objectives via structured question-answering

## Target count

4-6 pillars. More dilutes authority; fewer under-serves the ICP.

## Draft candidates (pre-audit hypotheses)

- Donor Retention
- Grant Writing for Small Nonprofits
- First-Time Nonprofit Setup
- Major Donor Cultivation
- Annual Fundraising Campaigns
- Donor Database Management / Data Hygiene

These are starting hypotheses. The Phase 1 audit will validate, eliminate, or replace them based on:
- Current site authority and topic coverage
- Keyword opportunity (volume, difficulty)
- ICP search behavior
- Competitor positioning gaps
