## Change protocol

1. Draft proposed change (in PR or discussion)
2. Review with Rob (CMO)
3. Commit with message: `strategy: <what> — approved by Rob <YYYY-MM-DD>`
4. If downstream skills reference this doc, update their context loaders (flag in commit body)
