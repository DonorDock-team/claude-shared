# Sales Enablement — Claude Project

**Goal:** Give DonorDock's sales team (1-3 people) instant, accurate answers to prospect questions by building a Claude Project loaded with curated enablement docs.

**Status:** Building initial content set

**Key files:**
- `system-prompt.md` — The system prompt for the Claude Project (copy into Project Instructions)
- `objection-handling-playbook.md` — Top objections with response frameworks
- `competitor-battlecards.md` — Side-by-side positioning against Bloomerang, Network for Good, DonorPerfect, Givebutter, Neon CRM
- `product-knowledge-base.md` — Feature/benefit reference organized by product area
- `maintenance-guide.md` — How to keep everything current

**How to set up:**
1. Create a new Claude Project
2. Paste `system-prompt.md` content into the Project Instructions field
3. Upload the three content docs as Project Knowledge files
4. Share the Project link with the sales team
5. Follow `maintenance-guide.md` for ongoing updates
